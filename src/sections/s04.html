S04

切源面板

myBox 最常用的操作。一个面板里同时完成三层选择：哪个仓库（或媒体服务器）、哪条线路、哪个站点。默认按「最近使用」排序，并带上每个站点的实测延迟，选源时不用盲猜。

rate_review对这一屏提意见
push_pin标注
  1. 点播 / 直播：在直播页打开同一个面板时默认选中「直播」，列出 lives[]。
  2. 仓库与服务器：每个配置地址是一个仓库；Emby、Jellyfin、WebDAV 与仓库并列。形状按类型分配（见 2.3）。
  3. 线路：仓库是多仓订阅（urls）时出现，显示各线路的实测延迟；超时线路标红但仍可选。
  4. 查找与筛选：按名称或 key 查找；类型 Chip 由 type 和 api 特征推断（csp_ 为 JAR，.js 为 JS，.py 为 Python）。
  5. 最近使用：最多 3 个，正好对应源胶囊的左右滑动顺序。
  6. 站点行：形状图标、名称、类型徽章、能力图标（搜索 = searchable，筛选 = filterable）、健康点与延迟。当前站点整行使用容器色并打勾。
  7. 不可用站点：最近一次测速失败的站点降低不透明度，右侧给出「重试」，排序沉底，但不隐藏。
  8. 源胶囊滑动：滑动中，胶囊下方短暂出现前后两个站点名，松手即切换，并加一圈主色描边提示已变化。
  9. 撤销：切换后 4 秒内可撤销，回到上一个站点及其滚动位置。
  10. 电视焦点：焦点站点图标从曲奇形变为晴日，卡片反色放大。
  11. 按键提示：电视面板底部常驻，告诉用户每个键能做什么。

界面字段 / 行为
仓库配置地址（含 ;pk; 密钥、clan:// 等 scheme），历史记录 api_history
线路多仓订阅 urls[{url, name}]；默认取第一条可加载的（§3.9），用户手动选择后记住
站点列表sites[] 的 key / name / type / api，默认按 indexs 排序，用户置顶优先
能力图标searchable、quickSearch、filterable
测速并发调用各站点 homeContent，超时取站点 timeout（钳制到 5–60 秒，默认 15）
直播 Tablives[] 的 name；格式由内容嗅探（txt / m3u）决定，不看扩展名
设为默认写入 home_api，下次启动直接进入该站点
gesture四种切源入口
  • 点源胶囊：打开本面板（手机底部面板 / 平板三栏 / 电视全屏）。
  • 滑源胶囊：最近 3 个站点之间直接切换。
  • 遥控器：菜单键打开面板；首页上按「频道 + / −」在最近站点间切换。
  • 被动切换：站点加载失败或片源失效时，页面给出「试试其他站点」，直接跳到 S09 同名换源。
