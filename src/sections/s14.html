S14

我的：历史与收藏

myBox 没有账号，「我的」就是这台设备上的记录：看到哪、收藏了什么、哪部剧更新了。历史和收藏都跨站点汇总，每一条记得自己来自哪个站点，点开直接回去，不需要先切源。

rate_review对这一屏提意见
push_pin标注
  1. 本机身份：没有登录。头像和名字只用于区分设备；页面写明记录只存本机，避免用户以为能跨设备同步。
  2. 统计：看过、收藏、追更、本月时长；点数字进入对应列表。
  3. 继续观看：与首页同一份数据，波浪进度条；已看完的不出现在这里，但仍在历史里。
  4. 追更提醒：每天在后台检查一次追更的剧，只在打开 App 时以角标提示，不发系统通知。
  5. 日期分组：今天、昨天、本周早些时候、更早；同一部剧多集只保留最近一条，展开可看各集进度。
  6. 多选：长按任一条进入，顶栏换成选择态；全选只选当前筛选下的条目。
  7. 两种删除：「移出继续观看」只隐藏卡片、保留进度；「删除」连同进度一起清掉，5 秒内可撤销。
  8. 有更新：以「新 N 集」红标置顶，进入详情后自动标为已读。
  9. 失效收藏：站点被删或改了 key 时变灰，点它进入 S09 同名换源，换到的站点会写回这条收藏。
  10. 平板概览：宽屏把各个列表的前几条拼成一页；下载与本机数据（保留条数、备份）放在底部。
data_object与规范的对应
界面规范依据
观看历史Room 表 vodRecord：vodId、updateTime、sourceKey、dataJson；按 (sourceKey, vodId) upsert（§8.9）
播放进度不在历史表里，写 cache 表，键为 md5(progressKey)，progressKey = sourceKey|vodId|flag|index，每站每线路每集独立（§8.9）
收藏Room 表 vodCollect：vodId、updateTime、sourceKey、name、pic（§8.9）
保留条数history_num（§5.8.0）
追更检测对追更条目重新请求详情，比较 vod_remarks 与 vod_play_url 中的集数（§4.3.5）
失效判定sourceKey 在当前配置的 sites[].key 中找不到；key 用于历史与收藏隔离（§3.3）
媒体服务器Emby / Jellyfin 条目的进度与收藏同步回服务器：/Sessions/Playing/Progress、PlayedItems、FavoriteItems（§10.10）
  • 备份格式：导出为一个 JSON，字段与 vodRecord、vodCollect、cache 三张表一一对应，可以从旧版 TVBox 的数据库直接导入。
  • 电视上：「我的」并入侧边导航的「历史」入口，多选改为焦点项上按菜单键弹出「删除 / 移出继续观看」。
