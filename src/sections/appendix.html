建议的技术实现

界面层
  • Kotlin + Jetpack Compose，minSdk 23（Android 6.0），一套代码覆盖手机、平板、折叠屏、双屏和电视。
  • 电视不使用 androidx.tv（tv-material、tv-foundation 都不引入），和手机共用同一套 Material 3 组件，焦点体系在 Compose foundation 上自建：
    • onFocusChanged 驱动「放大 + 白描边 + 主色光晕」
    • focusRestorer 让每一行记住上次的焦点
    • focusProperties 指定跨区域的方向键跳转，例如最左列 → 侧栏
    • onPreviewKeyEvent 统一处理菜单键、频道键和数字键
    • 列表用普通的 LazyRow / LazyColumn，通过 BringIntoViewSpec 让焦点项停在固定位置
  • Material 3 Expressive：MaterialExpressiveTheme、MotionScheme.expressive()、MaterialShapes、ButtonGroup、SplitButtonLayout、FloatingToolbar、LoadingIndicator、LinearWavyProgressIndicator。
  • 自适应：material3-adaptive 的 NavigationSuiteScaffold、ListDetailPaneScaffold；姿态用 androidx.window 的 FoldingFeature。
  • 模糊：dev.chrisbanes.haze（haze + haze-materials），按 2.2 节的材质表使用；API 23–30 用 fallbackColorEffect 着色层。
  • 取色：Coil 3 解码 + MaterialKolor 6.0：material-kolor-palette 的 rememberThemeColor 取种子色，material-kolor-material3 的 DynamicMaterialExpressiveTheme（PaletteStyle.Content，默认 SPEC_2025）生成主题。
协议与播放层
  • 配置：宽松 JSON 解析（容忍注释、单引号、尾逗号），相对路径以配置最终 URL 为基准（§3.8、§9.3）。
  • 爬虫：JAR 用 DexClassLoader；JS 用 QuickJS；Python 用 Chaquopy，作为可选构建风味（§7.13.9.7）。
  • 播放：Media3 ExoPlayer 为主内核，FFmpeg 扩展做软解；外部播放器按 §5.8.3 投递。
  • SMB：smbj（Apache-2.0）负责 SMB 2.0.2–3.1.1，smbj-rpc（BSD-3-Clause）列出共享；SMB1 只在用户确认后用 jcifs-ng（LGPL-2.1，作为独立依赖引入、不改源码）。smbj 依赖 BouncyCastle，Android 上要打包完整版，不能用系统自带的精简版。播放统一走本地代理转成 http 地址（§5.9）。
  • 本地服务：端口 9978 起递增，承载代理、远程管理与「附近 myBox」发现。
  • 许可：TVBoxOS-M3 为 AGPL-3.0，myBox 按规范重新实现协议，不直接复制其代码。

minSdk 23 的取舍

Android 6.0 是下限，大量电视盒子也停在 7–9。下面这些能力在旧版本上没有，界面按右列处理；设计稿里的每个界面都按「最低版本也能用」画，高版本只是更好看。

能力需要的版本低版本上的做法
实时模糊（RenderEffect）Android 12（API 31）Haze 的 fallbackColorEffect 着色层，即本稿「模糊」开关关掉时的样子
系统壁纸取色Android 12（API 31）设置里不显示这个来源；封面取色由 MaterialKolor 计算，任何版本都可用
画中画Android 8.0（API 26）播放器不显示画中画按钮，离开页面时暂停
可变字体轴（Roboto Flex 的字宽、字重）Android 8.0（API 26）改用固定字重，标题少了字宽变化，层级不变
预测性返回动画Android 14（API 34）普通返回，面板与页面仍有各自的退出动画
Let's Encrypt 证书（ISRG Root X1）Android 7.1.1 起系统内置很多配置地址用这类证书。OkHttp 用自定义 TrustManager 合并系统根证书与内置的 ISRG Root X1，否则 6.0–7.1 设备会加载失败
系统 WebView 版本解析与嗅探依赖较新的 WebView启动时检查 WebView 版本，过旧时在 S11 提示并优先用 JSON 解析

待讨论问题

下面这些是设计时拿不准、希望大家给意见的地方。每条都附上了当前稿子的做法。

编号问题本稿的做法
Q1封面取色应该取「面积最大」的颜色，还是「最鲜艳」的颜色？例如《长夜将尽》取到的是夜空的藏青 #101030，画面中心的橙色太阳只排第四。用 MaterialKolor 默认的 rememberThemeColor（kmpalette 量化 + Score，兼顾面积与彩度），可在 2.1 节逐张试。备选：用 rememberThemeColors(desired = 4) 取前几名，再挑彩度最高的一个。
Q2默认深色，还是跟随系统？默认深色，设置里可改为跟随系统或浅色。
Q3手机底部导航五项是否太多？「媒体库」能否并入切源面板，只保留四项？保留五项，因为 Emby / Jellyfin 用户的使用路径与 TVBox 站点差别较大。
Q4在源胶囊上左右滑动切换站点，会不会和 Hero 轮播的横滑冲突、造成误触？只在胶囊本身的区域响应，并在切换后给 4 秒撤销。
Q5电视默认关闭模糊是否合理？默认关闭，设备支持时可在设置里开启。
Q6切源面板打开时是否自动测速？会增加流量和站点压力。结果缓存 10 分钟，过期后打开面板时在后台测；也可手动「全部测速」。
Q7「继续观看」跨站点汇总，还是只显示当前站点的记录？跨站点汇总，每条记着来源站点，点开直接回到那个站点。
Q8播放失败时自动换到其他站点的同名影片，是否默认开启？默认只提示，不自动切换；设置里可以打开自动换源。
Q9片名使用宋体 Heavy，在低分辨率电视或小屏手机上是否够清楚？片名字号不小于 20 dp；小于这个尺寸时改用黑体粗体。
Q10是否需要「儿童模式」或「隐藏站点需要密码」？本稿未设计，若需要可放在设置的「数据」分组。
Q11Android 6.0–11 上是否打开 Haze 的实验性 RenderScript 模糊？不打开，统一用着色层。若希望旧手机也有玻璃质感，可以只给不滚动的面板（切源面板、对话框）打开。
Q12电视的切源入口放在侧栏最上面，是否够好找？侧栏顶部的源头像 + 全局菜单键，首次进入首页提示一次菜单键；右上角只留时钟。备选：把源头像放进顶部分类行的最左边。
Q13只支持 SMB1 的老设备（路由器硬盘、老 NAS）要不要支持？SMB1 有已知的安全问题，但这类设备在家里很常见。支持，但默认不连：发现时标出「仅 SMB1」，连接前弹出说明，由用户确认；确认后这个位置一直带着 SMB1 标签。
